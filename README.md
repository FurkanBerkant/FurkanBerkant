## 👋 About Me

I'm a **Software Engineer focused on Java backend development**, with professional experience building and operating backend services in **microservice** and **event-driven** architectures.

My day-to-day backend experience includes **Java, Spring Boot, Kafka, Redis, PostgreSQL/Cassandra, Docker and Kubernetes**, together with delivery and observability workflows using **ArgoCD, Prometheus and Grafana**.

I enjoy working on problems around **reliability, data consistency, asynchronous communication and backend architecture**. I'm currently deepening my knowledge of **distributed systems, Domain-Driven Design, system design and AWS**.

> Open to **Java Backend / Software Engineer** opportunities where I can contribute to real backend systems and continue growing in distributed architectures.
